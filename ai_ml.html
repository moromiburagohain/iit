Syllabus

Detailed module breakdown — expand to view topics and resources.

Module 101 Mathematics and Statistics: Delve into Linear Algebra, Multivariate Calculus, Statistics, and Probability. Learn Linear Regression, Outlier Rejection, and both Unconstrained and Constrained Optimization, including Stochastic Search with GA and PSO.

Module 102 Python Programming: Master Python Fundamentals, String Objects and Collections (Tuples, Set, Dictionaries, Functions). Get a thorough introduction to Pandas, covering basics, Series, Dataframes, text data, indexing, selecting, visualization, and critical data manipulation and cleansing techniques like handling missing values and skewness.

Module 201 Feature Space and Dimensionality Reduction, Unsupervised Learning, Generative Models, Pattern Mining: Gain proficiency with NumPy, SciPy, Scikit-learn, Seaborn, and Matplotlib. Understand the Machine Learning Task Workflow, Feature Space transformations, and separability. Explore Hashing Techniques for Feature Space Partition, Feature Subset Selection, Principal Component Analysis (PCA), Linear Discriminant Analysis (LDA), and Exploratory Factor Analysis (EFA).

Module 202 Unsupervised Learning, Generative Models, Pattern Mining: Explore various Unsupervised Learning techniques including Adaptive Thresholding, K-Means, Hierarchical Agglomerative Clustering, DBSCAN, Nonparametric Estimation, and Mean-Shift Clustering. Learn Performance Analysis of Clustering Algorithms, Parametric Estimation (Bias, Variance, MLE), Learning Mixture Models, Unsupervised Representation Learning, Probabilistic Latent Semantic Model (PLSA), Association Rule Mining, Suffix Tree and Sequence Mining, Markov Process, Hidden Markov Model (HMM), and Prediction with Autoregressive Process Models.

Module 301 Supervised Learning- Classification and Regression: Dive into Supervised Learning with Bayesian Classification, Logistic Regression, Perceptron, Multilayer Perceptron, K-NN, RBF ANN, Classification & Regression Trees, Ensemble Methods, and SVMs.

Module 302 Deep Learning and Computer Vision: Introduction to CNNs, RNNs, LSTM, Encoder-Decoder Networks, GANs. Practical CV skills using OpenCV for Feature Extraction, Object Detection, Face Recognition, Object Tracking, and Image Segmentation in DL Frameworks.

Module 401 NLP, Speech and Audio Processing: NLP with NLTK (Tokenization, Lemmatization, Morphology), n-gram models, Word2Vec, GloVE, Neural Language Models, CNN/RNN for sequence labeling. Speech processing with LibRosa for feature extraction, recognition, and synthesis.

Module 402 ML on Cloud, Counselling and Final Project: Cloud fundamentals and ML tools on AWS, Azure, GCP. Career counselling, interview tips, Capstone project, and final presentation.
