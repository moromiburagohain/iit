VLSI & Semiconductor Industry Essentials
Section Topic / Module Sub-Topics & Scope Weightage (Tentative)
I Engineering Mathematics Linear Algebra, Differential Equations, Probability, and basic Discrete Mathematics as applied to engineering concepts. 50 Marks
II Basic Python Programming Fundamental syntax, data types, control flow (loops, conditionals), functions, and basic object-oriented concepts. Focus on logical problem-solving. —
III Basics of Electronics Semiconductor devices (diodes, transistors), fundamental circuit laws (Ohm's, KCL, KVL), RLC circuits, and basic digital logic gates. —
Cyber Security
Section Topic / Module Sub-Topics & Scope Weightage (Tentative)
I Engineering Mathematics Linear Algebra, Probability, and Statistical methods relevant to security and data analysis (similar to the VLSI syllabus, but focus may shift to probabilistic models). 50 Marks
II Basic Python Programming Fundamental syntax, data types, control flow, functions, and file handling. Emphasis on scripting for automation and basic network operations. —
III Basics of Operating Systems(OS) OS types, process management, memory management, file systems, and fundamental OS security concepts (users, permissions, access control). —
Applied ML & DS
Section Topic / Module Sub-Topics & Scope Weightage (Tentative)
I Engineering Mathematics Covers fundamental concepts in:
  • Linear Algebra (Matrices, Determinants, Eigenvalues, Eigenvectors)
  • Calculus (Differential and Integral Calculus, Basic concepts of limits)
  • Probability and Statistics (Basic probability, Conditional probability, Mean, Median, Mode)
  • Discrete Mathematics (Basic Set Theory, Functions)
 50 Marks
II Basic Python Programming Focus on foundational programming skills:
  • Python Syntax and Data Types (Lists, Tuples, Dictionaries, Sets)
  • Control Structures (If-Else, Loops: For, While)
  • Functions and Modularity
  • Basic Input/Output and File Handling
  • Problem-solving through fundamental programming logic
 —
III Basics of Database Management Systems(DBMS) Covers core concepts related to data organization and management:
  • Database Architecture and Models (E-R Model, Relational Model)
  • Structured Query Language (SQL) Fundamentals (SELECT, INSERT, UPDATE, DELETE, basic JOIN operations)
  • Normalization (1NF, 2NF, 3NF)
  • Basic Concepts of Transactions and Concurrency Control
 —
